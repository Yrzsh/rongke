# 机制图工艺规范（给 AI 的 Origin · 第二版）

日期：2026-11-14
落点：`rongke/svgdiagram.py`（几何与规则）、`rongke/diagram_craft.py`（工艺审计）、
`rongke/caps_ext/svg_diagram.py`（回执）
判据：`diagram_craft_test.py`（新增）、`diagram_quality_test.py`（A14 基准随折行改写）

## 为什么要这一层

七道门只能保证「没画坏」：字装得下、不重叠、标记数对得上。它保证不了
「像期刊插图」。而下面这些问题是**每张图都会犯**的，不是某一张的偶然：

1. 颜色按图元序号轮 ⇒ 一张图里出现彩虹，读者会以为同色 = 同通路。
2. 长标签按整行反解外形 ⇒ 一个圆直径 182px、整图 1234px，摆进 180mm 版面字号掉到 4pt。
3. 按字硬断词 ⇒「磷酸化」被断成「磷酸／化」、「SMAD2/3」被断成「SMAD2/」+「3」。
4. 边标签压到虚线框或别的连线上 ⇒ 字糊成一团。
5. 层号来自图深度 ⇒「胞质」被排到「核」后面，两个区室框整块互套（量到 311×76px）。
6. 回边默认摆在重心位 ⇒ 反馈线从整张图中间斜穿过去。

靠人一张一张看、再改一张，等于把工艺留在人手里，工具本身没变好。
这一版把它们**沉到引擎规则 + 可回归判据**：引擎照着规则生成，审计照着
规则回查，AI 每次出图拿到结论与修法。

## 六条规则（引擎做什么 / 审计量什么）

| 规则 | 引擎侧（几何） | 审计侧（craft） | 判据负控 |
|---|---|---|---|
| 配色语义 | 描边色 = 所在区室的色；无区室回落墨色；判断框砖红 | 同区室必须同色；色数 ≤ 区室数 + 2 | 同区室改两色 ⇒ 红 |
| 尺度均衡 | 圆/六边形/菱形有外形上限（`_CIRCLE_MAX_D` 104、`_HEX_MAX_W` 150、`_DEC_MAX_W` 208），先收窄折行再反解 | 宽差 ≤ 3.4 倍；方框高差 ≤ 3.0 倍 | 单节点撑到 4 倍 ⇒ 红 |
| 折行质量 | 断点只在词边界：ASCII 词整体、中文连续字整体；末行孤字回补；行高 1.45（实测字盒 14.2px > 13.5px 会压 0.5px） | 英文词不许被拆、末行不许孤字 | 「磷酸／化」⇒ 红 |
| 标签压线 | 标签钉在空档正中；横向让位后**逐条避让**别的连线（`_AVOID_STEPS`），白底光晕（`cls="frame"`，不计 mark）；字盒宽按 ASCII 占比加权（`_label_em`，纯西文 ×1.25 —— 实测「SMAD7」盒/前进 = 1.32，固定 1.06 对西文差一截） | 标签框不许与别的边线、节点框**或别的标签**相交（最后一条 svgq 碰撞门看不见，由 craft 自查） | 标签挪到线上 ⇒ 红；两标签叠一起 ⇒ 红 |
| 区室不嵌套 | 按相邻层 run 拆框；同层撞上时两块框都裁到两组成员的中缝，被裁边上的区室名改贴另一侧 | 重叠面积 ≤ 小框 6%；成员共占同一层 ⇒ WARN（层序问题，不是裁框能修） | 两框重合 ⇒ 红/警示 |
| 回边不穿节点 | 没声明通道的回边默认走边侧（`bottom`/`right`） | 回边折线不许穿过任何节点框 | 折线穿过节点 ⇒ 红 |

配套一条版面账（`fit`）：按声明宽度摆放时正文折合几 pt、换方向后的 1:1
物理尺寸与字号。以前只说「改 TB」，AI 不知道改完能不能装下，只能试两次再放弃；
现在是算术。

## 视觉语法（第二版，2026-11-14）

前六条只管「不出错」，出来的图仍然不像期刊插图。第二版补的是**观感语法**，
全部由引擎常量决定——不是每次调用可调的参数，所以每张图都长这样：

| 元素 | 期刊语法 | 反例（第一版） |
|---|---|---|
| 区室 | 浅色相背景块，`rx=8`、**无描边**，组名用同色相小字 | 虚线框紧贴节点，框自己变成第二个节点 |
| 节点 | 白底 + 区室色**1.2px**细描边，`process` 圆角 4 | 1.6px 粗框，视觉重量压过连线 |
| 连线 | **1.1px**，箭头 7×3.2 | 1.5px 线配 9×4 大三角 ⇒ 网页流程图 |
| 字号 | 正文 10 / 边标签 8.5 / 组名 8.5 / 标题 11 粗体 | 组名 9、标题 12 抢戏 |
| 形状上限 | 圆 ≤104、六边形 ≤150 —— 与方框同量级 | 圆 132，整图第一眼是两个大圆 |
| 画布 | **宽度 = 内容自然宽度**，`width_mm` 只算「摆进版面缩到几 pt」 | 撑到声明宽度，两侧各几百像素空白 |

配套两条可执行回执：
- 内容比版面窄 ⇒ 警告写明「按 73mm 出」，并给两种修法（加内容 / 把 width_mm 改成 73）；
- 成员被别的区室夹住 ⇒ 该块改画近乎白（`_soften(..., 0.94)`），不再出现
  「蓝底里贴一块紫补丁」。

## 回执怎么读

`diagram_svg` 的 `payload.craft` = `{ok, items[], must_fix[], metrics, scope, honest_limit}`。
`next` 里会写：

- 全绿：`工艺审计通过：N 色 / 宽差 X 倍 / 折行 M 个 / 回边 K 条`；
- 有红项：`⛔ 工艺审计未过（n 项）` + 逐条 detail + 修法 + 「没过就别交付」。

AI 的做法只有一条：改**规格**重画到 `craft.ok=true`，不许手改 SVG 字节。

## 如实边界

- 审计是**几何 + 清单口径**：量的是结构（色、尺度、断词、相交、重叠），
  不是审美。留白呼吸感、箭头亲和度、色相观感仍要看图；浏览器缺席时
  `svgq` 的实测层同样判「审不了」，不冒充通过（`honest_limit` 写在回执里）。
- 「成员共占同一层」导致的两框互叠只报 WARN：根因是层号按图深度排，
  不是裁框能修的。彻底解法是「区室按声明顺序落层」，牵动环拆解与虚节点
  插入，本版没做，记在这里不假装解决。
- 规则只覆盖已经踩到过的六类坑；新坑出现时先写负控，再改引擎。

## 2026-11-14 补三：插图模式 —— 细胞不是色块

用户拿 BioRender 式参考图对比后确认：前两轮把**流程图**做干净了，
但科研机制图的单位不是矩形，是**有内部结构的图元**。这一轮加的是图元库。

### 规则

- 节点写 `icon` 就走插图模式：图元 + **下方标签**，不再套框；
  `label` 留空则不写字（细胞器可以不标）。
- `rongke/svgbio.py` 是图元单源：`cell_t / cell_cd4 / cell_b / cell /
  nucleus / er / golgi / mito / protein / dna / mrna / ribosome / antibody /
  mhc / liposome / virus / lysate`。每个图元在 100×100 局部坐标里画，
  放图时缩放到 `ICON_SIZE` 的默认包围框（细胞大、分子小）。
- 立体感来自**径向渐变 + 局部高光/颗粒**，不是滤镜：无外部依赖，
  SVG 单文件，可直接进 AI/PPT 继续编辑。
- 非均匀缩放会拉扁描边，所以图元元素一律带
  `vector-effect="non-scaling-stroke"`（放在 `<g>` 上无效，必须落到图形元素）。
- `groups[].kind="cell"` 时区室画成**一圈细胞膜**（外粗内细 + 极浅胞质），
  成员在膜内；否则仍是浅色相背景块。
- T 细胞红 / CD4 绿 / B 细胞蓝且带 Y 抗体：**图元自带生物语义色**，
  不被区室色统一染掉。图元不够就老实说，不拿矩形冒充细胞。
- 状态面（`diagram_state`）同步支持 `icon` 与 `groups.kind`，
  写错图元名在 add_node/set_node 就报错，并列出可选图元。

### 判据

`svgdiagram_test.py` F 段：插图模式结构自检、径向渐变存在、膜是椭圆、
图元标签不丢、无标签细胞器不占空行、未知 icon 报错（负控）。

补：TB 方向抓到一处真 bug —— 边标签让位的出界检查一律拿 y 对画布宽，
所有候选位置都被判出界、让位从未生效（交叉斜边上的「辅助」压线）。
修为沿 cross 轴检查，并允许 TB 在空档内上下微调 ±14px。判据 F7/F8。

## 2026-11-14 补四：胞内散布与膜的体形

第一版插图模式的膜会被拉成一条「香肠」：DAG 只认边，没有边的 er/golgi/mito
被排到 layer 0 与疫苗并列，胞内一大片空白。

- **胞内散布**：`groups.kind="cell"` 里**没有连边**的图元不参与 DAG，按「贴膜内侧」
  的锚点（先斜角、再两侧、最后正上正下）重摆一次；碰撞了就换下一个角，全撞就原位不动。
  有边的成员一个都不挪（语义优先）。连线中点附近留作禁区，免得图元压到边标签。
- **膜的体形**：细胞膜与胞内散布的竖径都有最小高宽比 0.56。膜往上下长之前先探一下
  **膜外节点**，会压上就不长 —— 宁可扁一点也不把膜叠到别人身上。
- 判据：F9 孤立细胞器不再挤成同一列；F10 膜高宽比 ≥ 0.5。

### 如实边界

- 散布只覆盖**无连边**的细胞器。胞内有边的成员（核 → mRNA → 核糖体 → 肽）
  仍按 DAG 排成一条链，不是参考图那种「核居中、翻译在左下」的圆形胞内构图。
  要做那个，需要「区室内部自由摆位」这一类布局意图，本版没做。
- MHC 分子画在节点位置，不会自动贴到膜上；跨膜表达是语义，不是几何。
- 这是**示意图图元**，不是 BioRender 素材库：复杂组织结构、真实细胞
  形态超出 17 种图元时，要新画图元，不能靠缩放现有图元凑。
## 2026-11-14 补五：边语义与多 panel

「各种类型的机制图」不能只有激活/抑制/虚线三种关系，也不能一张图只讲一件事。

### 八种边语义

`arrow`（激活/流向）/ `inhibit`（抑制 T 杠）/ `dashed`（间接/假设）/
`phospho`（磷酸化，末端圆点）/ `bind`（结合，双向三角）/
`cleave`（剪切，末端双横杠）/ `secrete`（分泌，末端囊泡点）/
`degrade`（降解，末端叉号）。

末端标记全部是**显式几何原语**（多边形 / 圆），不用 `<marker>`：
`inspect_svg` 要逐点量得到，PDF 转换也不会丢。判据 F12 用 mark 数区分
「只有一根线」和「真的画了末端语义」。

### 多 panel 组图

顶层给 `panels=[{id?, label?, spec}]` + `cols`（默认 2），工具就把几张独立
机制图拼成 A/B/C 一张大图。**每个 panel 走自己的完整布局与结构自检**，
再把 SVG 片段平移拼起来；`defs` 的 id 逐 panel 加前缀，避免两张图的渐变撞名
（撞了就是整片图元变黑）。工艺审计逐 panel 递归，顶层 `panels` 清单里记录
每格版面框与子清单路径。

### 如实边界

- 同一对源/靶之间的多条边仍会叠在一条线上（没有端口分流）；
  要并列表达请拆成两条各自的路径，或等下一版做「多端口路由」。
- panel 之间没有自动对齐基线：各格内容高度不同时按格居中，
  不保证同一水平线；需要严格对齐时给每格相同的节点数 / 相同方向。
  （已改为顶部对齐 + 字母钉格顶，见补六。）
- 多 panel 的观感仍要看图：格间距、字母位置是常量，不随内容自适应。

## 2026-11-14 补六：图元库扩到 25 种 + 多尺度

原 17 种图元只覆盖「细胞 / 细胞器 / 分子」三层，组织、个体、微生物缺位，
「各种类型的机制图」就画不到动物实验、组织切片、菌群互作。

- 新增 8 种：`dendritic`（树突状细胞，分叉突起）/ `macrophage`（巨噬细胞，阿米巴轮廓）
  / `tumor`（肿瘤细胞，多核异形）/ `tissue`（组织切片，紧密排列的上皮样细胞）
  / `organ`（器官，抽象叶形）/ `mouse`（实验小鼠，侧视）/ `bacteria`（杆状菌 + 鞭毛）
  / `exosome`（外泌体，膜蛋白 + 腔内货物）。
- 尺度语义：细胞 74–82px、组织/器官 66–76px、病毒/细菌 34–54px、分子 28–58px；
  `ICON_SIZE` 是**单源**（节点尺寸、散布锚点、判据都读它）。
- 判据 F13：每个登记图元都能画出来、都有包围框、不小于 24px，
  且细胞 / 组织 / 个体三层都齐（多尺度机制图的前提）。
  图元总览见 `runs/probe_diagram_visual/diagram_icon_sheet.png`。
- 多 panel 版式修正：第一版「每格垂直居中」会让同一行的字母落在不同高度、
  读起来像四张截图。改成**每格内容顶部对齐 + 字母钉在格顶**。

### 如实边界

- 图元是**示意图**，不是解剖级插画：器官只到「叶形 + 血管点」，
  小鼠只有侧视剪影；投稿级医学插画仍要走 BioRender / 手绘。
- 25 种之外（神经元、血小板、中性粒细胞、类器官）要新画图元，
  不许靠缩放现有图元冒充。
- 「区室 = 一个细胞」时，组里**只有细胞级图元**（cell/cell_t/dendritic/tumor…）
  就**不另画膜** —— 否则是「细胞套细胞」的双层圈。想要胞内有结构，
 就必须真给组里加 nucleus/er/mito 这些节点，膜才会画。
- 膜是**椭圆**，面积大于成员的外接矩形：落在矩形四角的胞外节点会被膜圈进去
  （看上去「疫苗在细胞内」）。构图时把胞外节点放在膜的左右外侧（LR）或上下外侧
  （TB），或给它们单独建组。

## 2026-11-14 补七：图例（legend）

一张机制图里，膜、图元、线的颜色都在**替作者说话**：「这圈膜是细胞」「橙色是激活」
「这个圆点是磷酸化」。没有图例，读者只能猜，审稿人第一条意见就是「请说明符号含义」。

- spec 顶层给 `legend=[{label, icon}? 或 {label, color}]`，工具在画布底部排一行：
  小图元（或 17×14 描边色块）+ 名称，字号 9pt（比边标签大一档，读图例不该费劲）。
- 画布高度自动 +42px（24 行高 + 18 空档）；**空 legend 不占位**（负控判据 F14e）。
- 多 panel 组图也能带图例：顶层 legend 画在整图底部，一格一图例的写法也支持
  （子 spec 自己带 legend，各格各画）。判据 F14a–F14f。
- 图例是**读图契约**，AI 不该把「膜/激活/抑制」这些符号留在正文里解释。

### 如实边界

- 图例不做自动去重：同一项重复写会画两遍；条目多了会超宽（画布靠左排，
  右侧留白），超过 6–7 项建议拆到图注里。
- 图例图标是缩略（统一 24px 高），组织切片这类细节多的图元在缩略尺寸下只剩剪影。
