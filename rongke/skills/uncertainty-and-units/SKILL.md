# 单位与不确定度 · 最小判据

> 这是荣珂**自研**的 Apache-2.0 最小替代技能，不引用也不复刻任何第三方技能
> 的内容。目的只有一个：框架开源后，`stats-review` 这类预设在没有外部技能库
> 的机器上仍能拿到一份可用的复核口径。它**不**提供数值计算库 —— 需要 GUM
> 预算、蒙特卡洛传播或自动单位换算的人，请自行安装专业工具。

## 1. 单位：先量纲，后数字

一个数字没有单位就没有物理意义。审稿时按以下顺序问：

1. **每一个报告值都有单位吗？** 图轴标签、表头、正文括号里的值都要有。
   无量纲量要明写「无量纲」或给出比值定义，不能留空。
2. **量纲对得上吗？** 等式两边、差值两侧、比值分母，量纲必须一致。
   「浓度下降 3 mg/L」与「下降 3%」不是同一句话，不许互换。
3. **换算有没有写清基准？** ppm / ppb 必须说明是质量比、体积比还是摩尔比；
   % 必须说明是相对谁；温度要写 ℃ 还是 K，差值与绝对值不可混用。
4. **SI 词头有没有落在数字上？** 「0.003 mg」与「3 µg」等价，但同一张图里
   不许两种混排，否则读者会误读量级。

⚠️ 常见假成功：代码里 `float` 运算全部退出 0、结果是一位漂亮的数字，
   而单位在读取 CSV 时就被剥掉了。**「算得出来」不等于「量纲成立」**。

## 2. 有效数字与舍入

- 报告值的小数位不应超过其不确定度所支持的精度。
  不确定度一般保留 1～2 位有效数字，中心值舍入到**同一小数位**。
- 中间计算保留足够位数，**只在最后一步舍入**；逐步舍入会累积偏差。
- 「±」后面必须写清是什么：标准差 s.d.（描述样本离散）、标准误 s.e.m.
  （描述均值精度）、还是 95% 置信区间。三者**不可互换**，也不许只写「误差」。
- 图注里的中心量（均值 / 中位数）与误差口径必须和图上真实画的一致。
  画了箱线（四分位）却写「均值 ± s.e.m.」属于图表撒谎。
- 样本量 `n` 要与误差口径同时给出；没有 `n` 的 s.e.m. 无法复核。

## 3. 不确定度传播：先说清来源

任何不确定度声明都要能回答三问：

1. **哪几项输入带不确定度？** 逐项列出，不要只给一个合成结果。
2. **A 类还是 B 类？** A 类来自重复观测的统计，B 类来自仪器说明、
   校准证书或先验假设。来源不同，合成方式不同。
3. **相关性怎么处理？** 共用同一台仪器、同一批试剂、同一条校准曲线的量
   是相关的，按独立量直接方和根会**低估**总不确定度。必须显式说明假设。

不确定度预算表最少要含：输入量、估计值、标准不确定度、灵敏系数、
分布假设、贡献量。缺任何一列都无法复核。

## 4. 量级合理性（最便宜也最有效的一道门）

在写「结果显著」之前，先做一次只用量纲和常识的粗检：

- 结果与同类体系的历史区间差几个数量级？差 2 个以上必须先解释，再谈统计。
- 百分比是否可能越界（>100%、负浓度、负方差）？
- 归一化之后分母是什么？分母接近 0 时，比值会虚高。
- 物理上不可能的组合：负绝对温度、效率 > 1、p 值 > 1、样本量小于分组数。
- 图上坐标范围是否把 0 基线裁掉，从而夸大微小差异？柱状图尤其要查。

## 5. 复核输出格式

复核结论必须**逐条可判定**，不许写「整体看起来合理」这类不可证伪的话：

```
[PASS] 所有报告值均带单位，图轴与表头一致
[FAIL] 图 2 图注写「均值 ± s.e.m.」，图上画的是箱线（四分位）→ 口径不符
[UNKNOWN] 未提供重复观测原始数据，A 类不确定度无法复核
```

`UNKNOWN` 是独立一态：**读不到 ≠ 不符合**，也不算通过。
把「没测到」写成「没问题」是本技能最反对的一件事。

## 6. 与荣珂门禁的关系

这份技能是**方法论输入**，不是门禁。荣珂的完成判定只认工具台账里读回来的
结果（`audit_figure` / 证据门 / 复核器），不采信模型自称「已按本技能核对」。
技能的作用是让模型知道该检查什么，判据的作用才是判定检查有没有真发生。
